1. 概要

本アプリは、Leaflet の地図上に潮汐観測地点・港を表示し、マーカーまたは地図上の任意地点から潮見表（タイドグラフ）ページを開く Web アプリである。JavaScript のみで動作する単一の index.html で構成され、サーバー側の処理は不要である。潮位の基準データには、気象庁「潮位表」の天文潮位（推算値）を用いる。

2. ファイル構成

index.html：アプリ本体（HTML・CSS・JavaScript を一体化）。proxy.php：任意。ブラウザから気象庁のデータを直接取得できない場合のみ使用する中継スクリプトであり、直接取得できる環境では不要である。

3. 地図と地点マーカー

気象庁の観測地点（赤）：全国 239 地点を index.html 内に埋め込んでおり、起動と同時に表示する。通信は不要である。

NOAA の観測地点（青緑）：米国の潮汐予測観測点で、NOAA の API から起動時に取得する。約 3,500 地点である。

OpenStreetMap の港（灰）：港・漁港・マリーナ・フェリーターミナル・港湾地区を、Overpass API から日本周辺 17 区画に分けて取得する。取得結果は localStorage に 7 日間キャッシュし、失敗した区画は次回の読み込み時に再試行する。複数の Overpass サーバーを順に試す。

任意地点：地図上の任意の場所をクリックすると、その緯度経度（小数 2 桁）の地点として潮見表へのリンクを表示する。

マーカー操作：マーカーのクリック判定は見た目より広く取っている。クリックすると地点名、種別、基準観測点、緯度経度、潮見表へのリンクをポップアップで表示し、カーソルを合わせると地名を表示する。

画面部品：左上に ℹ️ ボタンと 🔍 ボタンのみを置く。ℹ️ は使い方と読み込み状況、🔍 は Nominatim による地名検索を開閉する。いずれも初期状態では閉じている。

4. 潮見表ページ

地図の上に重ねて全画面表示し、「地図に戻る」で閉じる。内容は次のとおりである。

グラフ：SVG による 0〜24 時の潮位曲線で、単位は cm である。満潮（赤）と干潮（青）の点に時刻と潮位を数字で併記する。当日の場合は現在時刻の縦線を表示する。画面幅に応じて描画し、スマホでは文字を大きく、縦を高くする。画面幅が変わった場合は再描画する。

日付移動：「前日」「今日」「翌日」のボタンと日付入力欄で移動する。

潮名と月齢：日付の横に大潮・中潮・小潮・長潮・若潮のバッジを表示し、その下に月齢を表示する。

基準観測点の選択：任意地点や港の場合、最寄りの気象庁観測点を最大 5 件までプルダウンで切り替えられる。

注記：データの種類、基準面、偏差を含まないこと、安全判断には公式資料を確認すべきことを下部に表示する。

5. URL 仕様

ハッシュ形式で、静的ホスティングでもブックマーク・共有ができる。形式は #/tide/地点ID/YYYY-MM-DD である。地点 ID は、気象庁観測点が j_AK（地点記号）、NOAA が us-9414290（観測点番号）、任意地点・港が pt_34.67_134.88（緯度_経度）である。任意地点では、基準観測点を pt_34.67_134.88~EI のように末尾に付けて指定できる。ハッシュが無い場合は地図を表示する。

6. 潮位データの取得と処理

気象庁のデータ：年ごとのテキストデータ（https://www.data.jma.go.jp/kaiyou/data/db/tide/suisan/txt/年/地点記号.txt）をブラウザから直接取得する。取得できない場合に限り proxy.php を経由する。1 行が 1 日分の 136 桁で、毎時潮位 24 個（各 3 桁）、年月日、地点記号、満潮 4 組、干潮 4 組から成る。満干潮の時刻は「時 2 桁＋分 2 桁」でそれぞれ空白埋めであり、欠測は 9999 と 999 で表される。

曲線の作成：毎時潮位と満干潮の点を合わせ、前後の日の値で端を補い、滑らかな曲線で描く。満干潮の前後 25 分以内の毎時点は除外して曲線の乱れを防ぐ。

基準観測点の決定：任意地点・港では、最寄りの気象庁観測点を既定とし、距離が 60 km 以内の場合に採用する。候補は 120 km 以内の上位 5 件である。60 km 以内に観測点がない場合は海洋モデルに切り替える。

海洋モデル：Open-Meteo Marine API の sea_level_height_msl（約 8 km 格子、平均海面基準）を用いる。指定地点が陸地の格子の場合は、周囲約 0.25° 以内の格子を同時に問い合わせ、最初にデータのある格子を使う。

NOAA：満干潮の予測（MLLW 基準）を取得し、極値の間をコサイン曲線で補間する。

潮名の算出：月齢を、ユリウス日から 29.530588 日周期で求める。この月齢を半周期 14.765 日で割った余りの整数部 k により、k が 0〜2 と 14 のとき大潮、3〜5 と 11〜13 のとき中潮、6〜8 のとき小潮、9 のとき長潮、10 のとき若潮とする。2026 年 11 月分について、Surf life の表示と全日一致することを確認している。

7. 利用する外部サービス

いずれも無料で、API キーは不要である。気象庁：潮位表テキストデータ。NOAA CO-OPS：米国の潮汐予測。Open-Meteo Marine：海洋モデルの潮位。OpenStreetMap：地図タイル、Overpass API（港の位置）、Nominatim（地名検索）。Leaflet：cdnjs から読み込む。

8. 動作環境と保存データ

http または https で配信する環境で動作する。file:// で直接開くと地図タイルが表示されない場合がある。ブラウザの localStorage には、OpenStreetMap の港の取得結果のみを保存する。サーバーへ送信する個人情報はない。

9. 制限事項と注意

気象庁の潮位表は当年と翌年分のみ公開されるため、それ以外の年は表示できない。表示値は天文潮位の推算値であり、気圧や風による偏差、高潮は含まない。基準観測点は直線距離で選ぶため、瀬戸内海のように場所による潮時の差が大きい海域では、実際の潮時とずれることがある。その場合は基準観測点のプルダウンで比較する必要がある。OpenStreetMap の港は位置情報のみで、潮位観測所ではない。海洋モデルの値は参考値である。航海・釣り・潮干狩りなど安全に関わる判断には、海上保安庁・気象庁の公式資料を確認すべきである。公開する場合は、出典として「気象庁 潮位表」「OpenStreetMap」などを表示することが望ましい。
