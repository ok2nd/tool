テキストエディタ-50（Python / tkinter 製）の使い方

1. 起動とファイルの扱い

起動

テキストエディタ-50.pyw をダブルクリックすると起動します。事前に Python 3 と、ドラッグ＆ドロップ用のライブラリが必要です。

pip install tkinterdnd2

ファイルを開く

  • ドラッグ＆ドロップ：ファイルをエディタのウィンドウにドロップします。
  • コマンドライン／「送る」：テキストエディタ-50.pyw ファイル名 のように、起動時にファイルを指定します。

「開く」ボタンはありません。開いたファイルの名前は、画面上部のグレーの帯に表示されます（新規のときは「新規ファイル」）。

編集中にほかのファイルをドロップすると、「変更が保存されていません。保存しますか?」と確認されます。「はい」で保存してから開き、「いいえ」で保存せずに開き、「キャンセル」で何もしません。

保存する

右上の青い 保存 ボタンを押します。

  • 開いたファイルは、そのファイルに上書き保存します。
  • 新規ファイルは、保存先を選ぶ画面が開きます（拡張子は既定で .txt）。
  • ウィンドウを閉じるときも、未保存なら同じ確認が出ます。
Ctrl+S での保存はできません。保存ボタンを使ってください。

3. 検索

  1. 検索欄に文字を入れ、Enter または 先頭から検索 を押します。最初に見つかった箇所が青く選択されます。
  2. 続けて 次を検索（F3）で次の箇所へ、前を検索（Shift+F3）で前の箇所へ移動します。

便利な使い方

  • 編集エリアで文字を選択して Ctrl+F を押すと、選択した文字が検索欄に入ります。
  • Esc で、検索結果の青い表示と選択を解除します。
  • キーを押して編集すると、青い表示は自動で消えます。

オプション

チェック動作
大文字小文字を区別オフのときは区別せずに探します（既定）。
\n(改行)、\t(タブ)使用オンにすると、検索欄・置換欄の \n を改行、\t をタブとして扱います。オフでは、バックスラッシュと n などの文字そのものを探します。
検索は文末に達しても自動で先頭に戻りません。見つからなくなったら、もう一度 次を検索 を押すと先頭から探し直します。「見つかりません」のメッセージは出ません。

4. 置換とUNDO

  1. 検索欄に探す文字、置換欄に置き換える文字を入れます（Ctrl+R で置換欄へ移動できます）。
  2. 置換 を押します。最初の該当箇所が選択され、画面右上に「置換確認」が開きます。該当がなければ何も起こりません。
  3. ダイアログで選びます。
ボタンキー動作
はいY選択中の1件を置換し、次の該当箇所へ進みます。
いいえN置換せず、次の該当箇所へ進みます。
キャンセルEscダイアログを閉じます。
すべて―文書全体を一括で置換し、件数を表示します。

ダイアログが開くと、日本語入力（IME）は自動で半角に切り替わるので、Y・N がそのまま使えます。

UNDO（置換を元に戻す）

  • 1件ずつ置換した場合：UNDO を押すたびに、直前の1件が置換前の文字に戻ります。戻った文字は選択状態で表示されます。
  • 「すべて」で置換した場合：UNDO を1回押すと、全件が置換前に戻ります。カーソルと表示位置も置換前の状態に戻ります。
  • 置換のあとに行った入力なども、UNDO を押すと新しい順に取り消せます。
  • 戻す操作がないときは、「元に戻す操作がありません。」と表示されます。

5. タブキーの設定

保存 ボタンの左で、Tab キーを押したときの動きを選びます。

項目選択肢内容
タブタブコード（既定）タブ文字を1つ挿入します。
スペース次のタブ位置までのスペースを挿入します。例：4桁で「ab」の後ろなら2個、行頭なら4個。
タブ桁8桁（既定）／4桁タブの幅です。タブ文字の表示幅も、この桁数に変わります。

複数行を選択しているとき

  • Tab：選択した各行の先頭に、タブ文字（またはタブ桁数分のスペース）を挿入します。
  • Shift+Tab：各行の先頭のタブを1つ削除します。「スペース」を選んでいるときは、先頭のスペース（最大でタブ桁数分）も削除します。
桁数を切り替えると、すでにあるタブ文字の幅も変わります。スペースで入力済みの部分は変わりません。

6. 折り返しと行番号

右端で折り返す をオンにすると、長い行がウィンドウの右端で折り返されます。折り返された2行目以降には行番号が付かず、空白になります。

ウィンドウの大きさを変えると、行番号は自動で調整されます。オフにすると折り返さず、横スクロールバーで横に動かします。

7. 編集の便利機能

ダブルクリックで単語選択

文字の種類が同じ範囲を選択します。次の種類をまたいで選択しません。

  • ひらがな
  • カタカナ（半角を含む）
  • 漢字
  • 半角英数字と _
  • 全角記号

半角の記号や空白をダブルクリックしても、選択されません。

URL のリンク

http:// や https:// で始まる文字列は、紺色の下線付きで表示されます。クリックすると、既定のブラウザで開きます。

9. 設定の保存と注意点

自動で保存される設定

ウィンドウを閉じるとき、次の内容が editor_config.json に保存され、次回の起動時に復元されます。

  • ウィンドウの大きさと位置
  • 「大文字小文字を区別」「\n \t 使用」「右端で折り返す」の状態
  • タブの種類（タブコード／スペース）とタブ桁（8桁／4桁）

このファイルは、エディタを起動したフォルダに作られます。設定を初期状態に戻したいときは、このファイルを削除してください。

注意点

  • 文字コードは UTF-8 のみに対応しています。Shift_JIS などのファイルは開けません。
  • 保存するときの改行コードは LF です。
  • 日本語フォント「MS Gothic」を使うため、Windows での使用を想定しています。
